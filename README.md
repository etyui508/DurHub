# DurHub

Roblox 全能型 Hub，移动端优先（Delta / Android / iOS），PC 端其他执行器同样可用。

## 使用

```lua
script_key = "你的卡密"
loadstring(game:HttpGet("https://durhub.bony-doorframe-shortly.top/loader.lua"))()
```

不填 `script_key` 也能跑，会弹框让你输入卡密，验证通过后自动记住（换设备需要重新验证）。

## 卡密

卡密由服务端校验，支持设备绑定、有效期与吊销。需要卡密请联系作者。

源码不下发到本仓库。

## 性能

循环调度复用缓冲、ESP 分级降频（高亮 20Hz / 文本 10Hz）、防甩飞外来部件改事件驱动、面板不可见时停掉列表刷新。

## 脚本接口

Hub 暴露了可编程开关，别的脚本可以直接调：

```lua
local hub = getgenv().DurHub
hub.Set("aim_en", true)      -- 开自瞄
hub.Set("esp_en", true)      -- 开透视
hub.Toggle("fl_auto")        -- 切连续甩飞
print(hub.Get("aim_mode"))   -- 读当前锁定模式
```
